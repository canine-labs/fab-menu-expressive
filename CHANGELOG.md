## 0.0.1

* Initial release.
* Implemented Material 3 Expressive FAB Menu.
* Features:
    * `FloatingActionButtonMenu`: Container managing state and staggered animations.
    * `ToggleFloatingActionButton`: Toggleable trigger FAB with rotation animation support.
    * `FloatingActionButtonMenuItem`: Unified pill-shaped menu items as seen in official Material 3 designs.
* Support for alignment-aware layout and customizable colors.
